# 项目构想

## 项目定位

Folder-Doodle 是一个在线制作 Windows 文件夹图标的微型网站。

它不只是一个格式转换工具，而是一个“文件夹图标创作 + 展示 + 下载”的小型创作平台。

核心理念：让用户为自己的电脑空间创造一点属于自己的个性。

## 核心页面构想

### 左侧：使用教程

帮助用户理解如何替换 Windows 文件夹图标：

1. 右键文件夹
2. 进入“属性”与“自定义”
3. 点击“更改图标”并选择下载的图标文件

### 中间：创作区域

核心创作体验参考 Doodle Cursor Maker 的轻量绘制感。

计划能力：

- Canvas 在线绘制
- 颜色选择
- 橡皮擦
- 图案编辑
- 实时预览
- 模板修改
- 图片上传处理

### 右侧：官方图标库

展示精选作品，方便用户直接下载或二次创作。

可包含：

- 图标预览
- 名称
- 作者
- 分类
- 下载按钮

## 第一版范围

v1 先完成一个小而完整的创作网站：

- 绘制
- 转换
- 下载
- 教程
- 官方图标库

暂不优先做：

- 用户社区
- 账号系统
- AI 生成
- Windows 本地一键修改工具
- 完整桌面美化生态

## 后续扩展

- v2：增强图标库与主题分类
- v3：开放用户投稿、收藏和分享
- v4：扩展到鼠标、壁纸、图标主题等桌面美化生态
