# Folder Doodle 项目初步构想记录

## 一、项目来源

灵感来源于一个名为 Doodle Cursor Maker 的网站。

该网站的特点：

* 用户可以在线绘制自己的鼠标光标
* 绘制完成后可以生成并使用
* 支持作品展示与分享
* 核心体验不是复杂功能，而是让用户创造一个属于自己的数字小物

项目希望复刻这种“小而有趣、提升日常幸福感”的体验。

---

# 二、项目定位

项目暂定方向：

## 一个在线制作 Windows 文件夹图标的网站

核心理念：

> 让用户为自己的电脑空间创造一点属于自己的个性。

不是单纯的文件格式转换工具，而是一个：

“文件夹图标创作 + 展示 + 下载平台”。

---

# 三、为什么选择文件夹图标

原因：

1. 文件夹是用户每天都会接触的电脑元素。
2. Windows 默认文件夹样式单调。
3. 修改成本低，但视觉反馈明显。
4. 用户会因为“小变化”获得满足感。

类似：

修改鼠标指针。

用户不是刚需，但使用后会觉得：

“我的电脑更像我的了。”

---

# 四、初步页面设计

整体采用三栏布局。

## 左侧：使用教程区域

目的：

解决用户不知道如何替换的问题。

内容：

通过图片展示：

Step 1：
右键文件夹

Step 2：
进入属性 → 自定义

Step 3：
更改图标 → 选择下载文件

目标：

让普通用户无需搜索教程即可完成替换。

---

## 中间：核心创作区域

类似 Doodle Cursor Maker。

功能：

* Canvas 在线绘制
* 颜色选择
* 橡皮擦
* 图案编辑
* 实时预览

用户可以：

* 自己画图
* 使用模板
* 上传图片进行处理

最终生成文件夹图标。

---

## 右侧：官方图库展示

展示优秀作品。

包含：

* 图片预览
* 名称
* 作者
* 分类
* 下载按钮

例如：

分类：

* 可爱
* 像素
* 游戏
* 梦幻
* 暗黑
* 简约

第一阶段可以由项目方整理作品。

未来可以考虑开放投稿。

---

# 七、部署方案

第一阶段：

使用海外静态部署。

例如：

* Vercel
* GitHub Pages

原因：

* 免费
* 部署简单
* 适合个人项目展示

暂不考虑：

* 国内服务器
* 域名
* 小程序
* App

如果未来用户量增加，再考虑：

* 独立域名
* 国内部署
* Windows客户端辅助程序

---

# 八、暂不做内容

为了控制项目范围：
